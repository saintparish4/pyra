Pyra is a free, open-source (AGPL-3.0), self-hostable records management system for US fire
departments, built around the January 2026 NFIRS→NERIS transition. Three private-equity-backed
vendors control this market; departments stay because twenty years of incident history is held
hostage in proprietary systems. Pyra exists so a department can own its records outright and
still meet its federal reporting obligation.

:::warning Early planning — not shippable

Pyra is at Phase 0. The incident model is built directly against the NERIS data dictionary, so
everything that encodes the schema is **paused pending official dictionary and sandbox access
from UL/FSRI**. Building against a guess would mean rewriting all of it.

Moving now: repo scaffolding, auth and tenancy, the app shell, deploy tooling, and these docs.

:::

## What works today

| Area | State |
| --- | --- |
| Docker Compose stack (Postgres, MinIO, API, web) | Runs — see [Deploy](./deploy.mdx) |
| Email + password auth, sessions, department scoping | Runs, provisioned by seed script — see [Admin](./admin.mdx) |
| Incident reporting | Not started — blocked on the NERIS dictionary |
| Legacy import | Interface only — see [Import](./import.mdx) |
| NERIS submission | Not started |
